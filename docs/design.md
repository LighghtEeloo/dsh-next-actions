# 设计：下一步建议

## 要解决的问题

一轮工作结束后，用户常常要自己想清楚下一句该说什么，再把它打出来。模型此时最了解刚发生了什么，
所以由它在收尾时顺手给出几步，用户点一下就能把完整指令放进输入框。

## 体验

```text
助手回答……
[▸ 工具过程组]  下一步建议 · 已生成 · 2

┌───────────────────────────────────────────────────────────┐
│ ▣ 修复已完成，改动集中在 src/api；目前只跑了类型检查。        │
│ [ ✦ 跑一下测试 ]  [ ✓ 补回归用例 ]  [ ⚠ 推送到远端 ]          │
└───────────────────────────────────────────────────────────┘
```

- **先承接，再提议**：卡片第一行是 1–2 句上下文，说明刚才做了什么、为什么是这几步。
- **最多 3 条**，按模型给出的顺序排列。悬停时显示完整指令（原生提示），不改变布局。
- **推荐**：模型至多标 1 条，固定排第一；按钮描边带品牌蓝，前置 ✦。
- **已使用**：看用户在下一轮实际发出的消息。原样包含某条指令 → 实勾 ✓；保留了它至少一半的相邻字对
  （改后发送）→ 铅笔；删光或无关 → 不标。只要有实勾就不显示铅笔；没有实勾时允许多个铅笔。
  已使用的按钮文字转为二级色。只点击、没发送不算使用。
  每个按钮只放一个前置图标：勾或铅笔 > ⚠ 需确认 > ✦ 推荐；状态都写进可访问名（已发送 / 改后发送 / 需确认 / 推荐）。
- **点击 = 填入，永不发送**：
  - 草稿为空，或草稿仍是卡片刚填入且未改动的文字 → 整段替换；
  - 草稿里有用户自己的内容 → 在光标处插入「空行 + 指令」，作为一次编辑器编辑，保留 `@` 引用，⌘Z 可撤销。
- **危险建议**：模型标记或本地词表命中时，按钮前加 ⚠，可访问名带「需确认」；同样只填入。
- **随会话保存**：卡片从会话日志重建，刷新、重启、回放后每一轮的卡片都在，历史卡片仍可点击填入。
  只有回合刚结束时出现的卡片做展开动画，打开历史会话时直接显示。
- **过程行**：工具过程组里只有一行「下一步建议 · 正在生成 / 已生成 · N / 未显示」，悬停「未显示」可见原因代码。

## 不做的事

不自动发送、不弹确认态、不提供设置页、不做单轮忽略按钮、不额外请求模型。全局关闭用 Host 配置 `enabled: false`，此时不注册工具与提示词，零 token。

## 机制

| 部分 | 文件 | 职责 |
| --- | --- | --- |
| Host | `index.js` | 为根 agent 注册 `suggest_next_actions` 与一段常驻提示；`enabled:false` 时什么都不注册 |
| 规范化 | `lib/normalize.js` | 参数 → `{ shown, context, suggestions[≤3] }`：折叠空白、截断、按指令去重、风险词标记、推荐至多一条且置顶。Host 写入 `tool/result.meta`；Client 内联同一份代码重读 meta 或回退到调用参数 |
| Client | `src/client.js` + `src/styles.js` → `client.js` | Conversation Definition 把本工具事件折叠进 `turn.data.get('next-actions')`（native 与 PTC `run_code` 两条通路）；`conversation.chat.turnTail` 渲染卡片；`tool.call.toolview` 渲染过程行 |

"已使用"不另存任何状态：同一个 Definition 还把每轮用户自己发出的 `user/message`（`source.kind === 'user'`）
折叠成该轮的 `sent` 文本；第 N 轮的卡片通过 `useChat` 的 `timeline.turnOrder` / `timeline.turns` 读第 N+1 轮的 `sent`
来判定。卡片与勾选状态因此都只来自会话日志，刷新、回放、换设备结果一致。手动输入了相近内容也会被标记——
"使用"指的是做了这一步，而不是按了这个按钮。

外部插件不能 require Harness Client 包，所以卡片沿用官方动作卡的边框、圆角、底色与字号，
类名用 `dshns-` 前缀，只引用 `--dsw-*` 主题 token。刚结束的回合用 CSS `grid-template-rows` 展开卡片，避免回答被一帧顶起；
`prefers-reduced-motion` 下不做动画。

## 待实机确认

- `insertText` 在含 `@` 引用的草稿里插入的位置与撤销行为（失败时会退回 `setDraft` 追加，此时引用会变成纯文本）。
- 0.2.2-rc.1 的 `useChat` 快照提供 `timeline.turns` 及其 `data`，`user/message.content` 为文本块数组。
- 改后发送的阈值（相邻字对保留 ≥50%）在真实消息上的效果。
- `turn.end.time` 的格式（决定只有刚结束的卡片才播放展开动画）。
